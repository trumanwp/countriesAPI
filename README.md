# 🌍 Country Explorer

A **React app** to browse and view details about countries — featuring dark mode and a fully responsive design.

---

## ✨ Features

- 🗺️ **Browse countries** with their flag, name, population, region, and capital  
- 🔍 **View detailed information** for each country  
- 🌗 **Toggle dark mode** (via `dark` class on `<html>`)  
- 📱 **Responsive layout** for desktop, tablet, and mobile  
- ⚛️ Built with **React**, **Tailwind CSS**, and **React Icons**

---

## 🎨 Styling

- Uses **Tailwind CSS v4** for utility-first styling  
- Dark mode is toggled by adding/removing the `dark` class on the `<html>` element  

---

## 🌐 Data Source

Country data is fetched from the **[REST Countries API](https://restcountries.com)**.
